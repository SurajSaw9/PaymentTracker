Install on iPhone (iOS) & Android

🍎 iPhone (Safari) — Home Screen App:

  1. Is page ko Safari mein open karein (hosted link ya local file).
  2. Neeche Share icon (box with arrow) par tap karein.
  3. Add to Home Screen chunein aur Add tap karein.

🤖 Android (Chrome / Brave) — Install PWA:

  1. Top-right ⋮ (Three Dots) menu par tap karein.
  2. Install app ya Add to Home screen chunein.
  3. App icon home screen par aa jayega aur full-screen chalega.
